# Agenda

Agenda pessoal para o celular: dia, calendário com fases da lua, listas de compras, contas, saúde e ciclo menstrual.

- Os dados ficam salvos só no aparelho (localStorage). Nada é enviado para servidor.
- `src/app.html` é o código do app. Rode `sh build.sh` para gerar o `index.html` instalável.
